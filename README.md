# Goyda Launcher

Лаунчер Minecraft для Windows 10 / 11, x64.

[Открыть сайт](https://goyda-launcher.up.railway.app/) · [Скачать последнюю версию](https://github.com/IvanK577/GL-releases/releases/latest)

Этот репозиторий содержит готовые установщики и контрольные суммы. Исходный код проекта хранится отдельно.

- **EXE** — обычная установка.
- **MSI** — пакет Windows Installer.
- **SHA256SUMS.txt** — контрольные суммы установщиков.
- **build.json** — версия, исходный коммит и состав сборки.

В выпуск 0.1.1 входит обновлённый Goyda HyperReal r3 с пресетами Low / Medium / High. Установщики пока без цифровой подписи.

Goyda Launcher — независимый проект. Он не связан с Mojang и Microsoft. Minecraft — товарный знак Mojang AB.
